# Streamlit-CSV-Data-visualizer
A simple interactive data analysis dashboard built using python , streamlit , pandas and matplotlip. Upload any csv file , filter data and download it and visualize via charts.
# Simple Data Analysis Dashboard

An interactive dashboard developed using *Python* and *Streamlit* that allows users to upload CSV files, analyze datasets, visualize data, and download filtered results.

---
##  Features
-  Upload CSV files
-  Display dataset statistics
-  Filter data using sidebar controls
-  Preview filtered data
-  Generate Line, Bar, and Scatter charts
-  Download filtered data as CSV
-  Clean and user-friendly interface
---
## Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib
---
##  Installation
Clone this repository

bash
git clone https://github.com/azhaguramkumar017aciet-bot/Streamlit-CSV-Data-visualizer.git
Install required packages
bash
pip install streamlit pandas matplotlib
Run the application
bash
streamlit run app.py
